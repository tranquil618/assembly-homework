# C 实现的实际反汇编及注释

## 平台与来源

下面是 `ASCII.C` 经 Apple Clang 21.0.0 编译后，对实际可执行文件进行反汇编的结果。
验证平台为 **macOS / ARM64**，使用 `-O0` 保留循环结构，源码采用 C89 语法。
**这份结果不是 8086/DOS 反汇编，不能作为课程 DOS 环境的实测记录。**
本文件夹的课程工具只有 MASM、LINK、DEBUG，没有 DOS C 编译器；当前电脑也没有可运行的 DOSBox。
两份 `.ASM` 按课程的 16 位 DOS 平台编写，C 源码则可在提供标准 `stdio.h` 的 DOS C 编译器上编译。

可复现命令（在 macOS 终端中，从本作业目录执行）：

```sh
xcrun clang -x c -std=c89 -Wall -Wextra -pedantic -O0 -g ASCII.C -o CHECK/ASCII_MAC
./CHECK/ASCII_MAC > CHECK/C_RUN.TXT
xcrun llvm-objdump --disassemble --no-show-raw-insn CHECK/ASCII_MAC > CHECK/C_DISASM.TXT
```

`CHECK/C_DISASM.TXT` 保留工具原始输出，下面只对其中 `main` 的指令逐行添加中文注释。
原始工具把调用目标显示成带有 `_putchar` 的符号表达式；这里按实际调用含义解释为 `putchar` 跳板。

## main 的逐行注释

```asm
100000410:  sub	sp, sp, #0x20                            // 分配 32 字节栈空间。
100000414:  stp	x29, x30, [sp, #0x10]                    // 保存帧指针 x29 和返回地址 x30。
100000418:  add	x29, sp, #0x10                           // 建立当前函数的栈帧。
10000041c:  stur	wzr, [x29, #-0x4]                       // 初始化编译器生成的返回值槽。
100000420:  mov	w8, #0x61                                // 把 0x61（ASCII 小写 a）送入 w8。
100000424:  str	w8, [sp]                                 // 保存 ch；ch 位于 [sp]。
100000428:  str	wzr, [sp, #0x8]                          // row = 0；row 位于 [sp+8]。
10000042c:  b	0x100000430 <_main+0x20>                   // 进入外层循环条件检查。
100000430:  ldr	w8, [sp, #0x8]                           // 读取 row。
100000434:  subs	w8, w8, #0x2                            // 比较 row 和 2，设置条件标志。
100000438:  b.ge	0x1000004b8 <_main+0xa8>                // row >= 2 时退出外层循环。
10000043c:  b	0x100000440 <_main+0x30>                   // 条件满足，进入外层循环体。
100000440:  str	wzr, [sp, #0x4]                          // col = 0；col 位于 [sp+4]。
100000444:  b	0x100000448 <_main+0x38>                   // 进入内层循环条件检查。
100000448:  ldr	w8, [sp, #0x4]                           // 读取 col。
10000044c:  subs	w8, w8, #0xd                            // 比较 col 和 13（0x0D）。
100000450:  b.ge	0x10000049c <_main+0x8c>                // col >= 13 时结束本行。
100000454:  b	0x100000458 <_main+0x48>                   // 条件满足，进入内层循环体。
100000458:  ldr	w0, [sp]                                 // 把 ch 放入参数寄存器 w0。
10000045c:  bl	0x1000004c8 <_putchar+0x1000004c8>        // 调用 putchar(ch)；目标地址是 putchar 的动态链接跳板。
100000460:  ldr	w8, [sp]                                 // 读取 ch。
100000464:  add	w8, w8, #0x1                             // 计算 ch + 1。
100000468:  str	w8, [sp]                                 // 保存更新后的 ch。
10000046c:  ldr	w8, [sp, #0x4]                           // 读取 col。
100000470:  subs	w8, w8, #0xc                            // 比较 col 和 12（0x0C）。
100000474:  b.ge	0x100000488 <_main+0x78>                // col >= 12 时跳过空格，即最后一个字母后不打印空格。
100000478:  b	0x10000047c <_main+0x6c>                   // 进入打印空格的分支。
10000047c:  mov	w0, #0x20                                // w0 = 0x20，即 ASCII 空格。
100000480:  bl	0x1000004c8 <_putchar+0x1000004c8>        // 调用 putchar(空格)。
100000484:  b	0x100000488 <_main+0x78>                   // 进入内层循环更新部分。
100000488:  b	0x10000048c <_main+0x7c>                   // 跳到 col 自增代码。
10000048c:  ldr	w8, [sp, #0x4]                           // 读取 col。
100000490:  add	w8, w8, #0x1                             // 计算 col + 1。
100000494:  str	w8, [sp, #0x4]                           // 保存 col。
100000498:  b	0x100000448 <_main+0x38>                   // 返回内层条件检查，继续打印本行。
10000049c:  mov	w0, #0xa                                 // w0 = 0x0A，即换行符。
1000004a0:  bl	0x1000004c8 <_putchar+0x1000004c8>        // 调用 putchar(换行符)，结束当前行。
1000004a4:  b	0x1000004a8 <_main+0x98>                   // 进入外层循环更新部分。
1000004a8:  ldr	w8, [sp, #0x8]                           // 读取 row。
1000004ac:  add	w8, w8, #0x1                             // 计算 row + 1。
1000004b0:  str	w8, [sp, #0x8]                           // 保存 row。
1000004b4:  b	0x100000430 <_main+0x20>                   // 返回外层条件检查，决定是否打印下一行。
```

## C 与反汇编的对应关系

| C 源码 | 反汇编中的主要动作 |
| --- | --- |
| `int ch = 0x61;` | 把 97 写入 `[sp]` |
| `row = 0; row < 2; ++row` | `[sp+8]` 保存 row，比较 2，`b.ge` 退出，`add` 自增，`b` 返回条件处 |
| `col = 0; col < 13; ++col` | `[sp+4]` 保存 col，比较 13，`b.ge` 退出，`add` 自增，`b` 返回条件处 |
| `putchar(ch)` | 把参数送入 w0，`bl` 调用 putchar |
| `++ch` | 读出 ch，加 1，再写回 |
| `if (col < 12)` | 比较 col 和 12，条件不满足时跳过打印空格 |
| `putchar('\n')` | 参数设为 10，再调用 putchar |
| `return 0` | 返回值 w0 设为 0，恢复栈帧，`ret` 返回 |

`bl` 是带返回地址的函数调用，`b` 是无条件跳转，`b.ge` 是有符号“大于或等于”条件跳转。
C 编译器用比较、条件跳转、加法和回跳实现 `for` 循环，并不必然使用 8086 的 `LOOP` 指令。
本例两个计数器存放在不同栈槽中；手写 8086 汇编共用 CX，因此必须保存和恢复外层 CX。

## 课程 DOS 平台上的 C 反汇编步骤（待实测）

若老师要求 C 部分也必须在 DOS 中完成，需要另外提供 DOS C 编译器，例如课程指定版本的 Turbo C。
以下以已配置 Turbo C 2.x 命令行编译器为例，属于操作步骤，不是本次实际运行记录：

```bat
tcc -O- ASCII.C
ASCII
DEBUG ASCII.EXE
```

DEBUG 中用 `u` 查看指令、用 `t`/`p` 跟踪程序、用 `g` 继续执行、用 `q` 退出。
C 程序入口通常先进入运行库启动代码，直接执行 `u` 看到的内容未必就是 `main`；
可另外用 `tcc -O- -S ASCII.C` 生成编译器汇编清单，查找 `_main`，辅助定位和对照。
`-S` 清单是编译器生成的汇编源码，**不是对 EXE 进行反汇编的结果**。
应在 DEBUG 中定位实际的 main 代码后再记录、加注释，地址与指令取决于编译器和编译选项，不能照抄上面的 ARM64 地址。
