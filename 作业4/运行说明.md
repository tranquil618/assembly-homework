# 九九乘法表

TABLE.ASM 使用双重循环、MUL 乘法和 PRINT_CHAR 过程输出乘法表。过程使用 PUSH/POP 保存、恢复 AX，通过 CALL 调用、RET 返回。
table.c 使用两层 for 循环输出相同排列的乘法表，根据乘积位数调整空格。

在 Mac 终端启动：

```sh
cd "/Users/tranquil618/codespace/大三/上/汇编语言/作业/作业4"
dosbox-staging --noprimaryconf --nolocalconf --conf DOSC.CONF
```

在 DOSBox 中输入：

```bat
CBUILD
TABLEC
```

CBUILD 使用 Open Watcom 1.9，启用 C99 语法，目标为 DOS 16 位、8086、小内存模型，关闭优化并保留调试信息。
C 版产物为 TABLEC.EXE，避免覆盖汇编版 TABLE.EXE。
原始目标文件反汇编为 TABLEC.DIS，中文注释版为 TABLEC_注释.txt。

反汇编阅读顺序：先看 i=9，再看外层判断、j=1、内层判断、IMUL、printf、j++ 和 i--。
本次 int 为有符号 16 位类型，因此 C 乘法编译成 IMUL；手写汇编使用 MUL，输入都是 1～9 时结果一致。
局部变量位置：i=[BP-2]、j=[BP-6]、mult=[BP-8]；[BP-4] 是编译器的返回值暂存区。
C 源码没有自定义输出函数，printf 是标准库函数；汇编版已单独实现 PRINT_CHAR 过程。
